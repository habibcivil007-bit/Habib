# Changelog

## 2.0.0 — 2026-09-30 (source release, not yet built)
- Standards generator + JSON data (114 colours, 87 layers, 12 filters, 55 members, 20 hatches, 29 blocks, 7 linetypes).
- Core library (units, rebar, BBS, BOQ, schedules, QA, exporters, ETABS JSON exchange, logging) + 37 xUnit tests.
- AutoCAD 2026/2027 plugin source: ~70 RNR* commands, WPF palette.
- AutoLISP suite: 15 modules, 34 commands.
- 12 sample DXF drawings for a 3-storey residence + PNG previews.
- Validation scripts, verification matrix, bundle manifest, WiX v6 installer, build scripts.
- Known: not compiled, not run in AutoCAD, DWT templates must be generated with RNRTEMPLATE.
