# Standards Reference

All standards live in `Standards/*.json` and are generated by `Scripts/generate_standards.py`
(single source of truth; edit the generator, rerun, then `validate_standards.py`). User overrides
go to `%APPDATA%\RooMNRooF\Standards` and are merged by `StandardsRepository`.

| File | Content |
|---|---|
| RNR_Colors.json | 114 TrueColor entries (id, rgb, nearest ACI) |
| RNR_Layers.json | 87 layers: colour, linetype, lineweight, transparency, plot flag, discipline |
| RNR_LayerFilters.json | 12 property filters |
| RNR_Members.json | 55 structural member types (layers, parameters, mark prefix, schedule) |
| RNR_Rebar.json | T8–T32 bars, unit weight d²/162.2 kg/m, BS 8666-style shape codes |
| RNR_Hatches.json | 20 material hatches (11 custom PAT in `Hatch/`) |
| RNR_Blocks.json | 29 block definitions |
| RNR_Styles.json | text/dim/mleader styles, annotation scales, A0–A4 sheets, title blocks |
| RooMNRooF.lin | 7 linetypes |
| RooMNRooF_Project.json | project metadata template |

Layer naming: `<Discipline>-<Major>[-<Minor>]`, disciplines A, S, C, P, E, M, ANNO, XREF, Z (non-plot/construction).
